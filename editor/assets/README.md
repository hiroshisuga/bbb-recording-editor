# Transition cue A

`cut-cue-a.wav` is an original synthesized two-note cue made for this editor:
48 kHz, mono, signed 16-bit PCM, exactly 250 ms. It is the approved sound A.
It has soft attacks and a faded tail, with RMS -25.5 dBFS. It contains no
recorded speech, third-party music, or external sample-library material.

`generate-cut-cue.py` reproduces the file using Python's standard library.
The sound is distributed as part of this project's LGPL-3.0 source tree.
